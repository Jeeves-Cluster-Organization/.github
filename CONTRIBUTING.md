# Contributing

These projects are single-maintainer-led, but contributions are welcome.

## Before contributing

- **Open an issue first** for non-trivial changes—let's discuss before you invest time
- Check existing issues and discussions to avoid duplicates

## Pull requests

- Keep PRs focused on a single change
- Explain the motivation and any trade-offs in your PR description
- Be patient—review may take time given the single-maintainer model

## Design discussions

For larger changes or new features, open a design discussion issue first. This helps align on direction before implementation.

## Expectations

Responses may not be immediate. If something is blocking you, feel free to fork and experiment.
